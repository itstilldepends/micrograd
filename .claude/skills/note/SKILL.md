# 记笔记到 NOTES.md

把本次对话中有价值的内容整理进 `NOTES.md`(repo 根目录)。这是用户的**私人学习笔记**,目标是为求职复习服务——标准是"能默写/能改"。

## 何时触发

用户说"记一下"、"记笔记"、"记到 NOTES"、"这段记下来"、"标进度"、"更新 NOTES",或直接 `/note`。

## 工作流(先草稿,后写入)

1. **确定记什么**:默认是本次对话**最近一次**有价值的问答;若用户指明了具体内容,以用户指明的为准。
2. **判断归入哪个区**(见下面"区与格式")。
3. **检查是否延续已有线程**:扫一遍「问答精华」,若新问答与最近若干条是同一主题的递进(如 现象→数学→本质),在草稿里一并**提议**线程标注:主题锚 `> 🧵 主题:…(N 连问,建议连读)` + 给同组标题加 `(1/N)…(n/N)` 序号。是否标注由用户决定,**默认只提议不强加**。
4. **先把草稿贴在回复里给用户看** —— 包括:进哪个区 + 完整文本(含可选的线程标注)。等用户确认或修改。
5. 用户确认后,用 Edit 把内容追加到 NOTES.md 对应区。**不要动其它区、不要重排已有内容、不要删现有注释**。

## NOTES.md 的区与格式

- **进度 / 代码掌握度**:勾选项。用户说"标进度 / 打勾"时,把对应 `- [ ]` 改成 `- [x]`。
- **核心概念笔记**(autograd / Python 机制 / nn 库 / 训练):放概念性理解。追加到对应小节,用 bullet,写用户自己的话。
- **问答精华**:放具体问答。格式:
  ```
  ### Q: <一句话问题> (YYYY-MM-DD)
  - <关键答案要点 1>
  - <关键答案要点 2>
  ```
  - **线程标注(可选,见工作流 step 3)**:同一主题的多条问答连读时,在该组第一条前加一行主题锚,并给各标题加序号:
    ```
    > 🧵 主题:<主题名>(N 连问,<递进概述>,建议连读)

    ### Q: <问题1> (YYYY-MM-DD) (1/N)
    ### Q: <问题2> (YYYY-MM-DD) (2/N)
    ```
- **TODO / 还没搞懂的**:用户说"这个先记着 / 下次再问"时放这。

## 规则

- 只动 `NOTES.md`。绝不动 CLAUDE.md、代码或其它文件。
- 日期取当天:运行 `date +%F` 获取,别硬编码。
- 沿用用户已有的**简洁**风格;代码引用用 `engine.py:17` 这种 `file:line` 格式。
- 保留 NOTES.md 现有的占位注释(`<!-- -->`)和整体结构,只在区内追加。
- 写完只说一句"记到了哪个区",不要长篇总结。
